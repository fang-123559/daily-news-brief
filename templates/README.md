# 模板库 · 格式重设计(三版 · 编辑印刷体系)

基于 `archives/2026-08-19.md` 真实样例数据的三版 HTML 邮件模板,与现版"报纸风"(`archives/email_template.css`)并存,发送前任选其一。

## 设计体系

三版共同遵循 **yanliudesign/mono-color-skill** 的编辑印刷语法(GitHub, 2k+ stars),只取其版式规则,不模仿任何参考构图:

> 中性纸基材 + 最多两种油墨(各承担明确"版角色") + 单一左缘对齐 + 25%-55% 主动留白 + 一次 5-12× 的字号跳跃 + 恰好一个手工手势

对应的**反 AI 味禁令**(来自该体系的 Hard Avoids,也是上一版三稿被否的原因):不做卡片网格、不做 UI 面板、不做胶囊徽章/贴纸、不做无角色分配的点缀色、不做居中模板对称、不做装饰色块——上一版的四色卡片、深色终端面板、评分胶囊全部移除。

## 三版配方

### V1 钴蓝规则单页 —— `v1-modern-cards.html`

- **版式家族**:ruled information poster(规则信息海报)。细钴蓝规线组织全部信息,数字即装饰。
- **基材**:Neutral White `#FAFAF7`;**油墨**:钴蓝 `#2148B8`(结构版:报头/规线/数字/标签)+ 碳黑 `#1F2328`(正文版)。
- **焦点事件**:56px 报头(对微缩字号 6.2×);**手势**:顶部规则市场数据带(表格数字 + 不等宽规则块)。
- **适用**:信息优先、冷静克制的日常阅读。

### V2 薄荷观察日志 —— `v2-editorial.html`

- **版式家族**:editorial journal(观察日志)。衬线长文阅读,批注语气。
- **基材**:Pale Beige `#F5F1E8`;**油墨**:炭黑 `#302D2E`(正文版)+ 薄荷绿 `#5EB783`(批注版:日期/标签/评分/圈注)——即该体系"日志、随笔、长文阅读"的指定双色配方。
- **焦点事件**:52px 衬线报头(5.5×);**手势**:全文唯一一处圈注——本期要点第 1 条的"均为优"被薄荷绿椭圆圈出。
- **适用**:重视 AI 点评与解读、喜欢"深阅读"的读者。

### V3 炭红公告 —— `v3-dark-terminal.html`

- **版式家族**:type-led declaration(文字主导宣言)。日期即头条。
- **基材**:Cool Gray `#E9E9E5`;**油墨**:炭黑 `#30343A`(主体)+ 信号红 `#C83232`(批注版:巨型日期/评分/变动数字)——"报告、公告、观念性作品"的指定双色配方。
- **焦点事件**:84px 红色日期 `08.19`(对微缩字号 9.3×);**手势**:一条出血出左缘的红规线。
- **适用**:开盘前快速扫盘的财经读者;日期醒目,变动数字全部红色标出。

## 三版共同约束

1. **内容板块不变**:报头 / 日期栏 / 今日要点 / 天气 / AI 动态(10)/ 国内新闻(10)/ 金融财经(5,含行情表)/ 国际新闻(5)/ 附录·四维打分 / 页脚免责。
2. **发送校验**:每版包含 `NumberAlign` 的 `@font-face` 定义(`send_email.ps1` 硬校验)。
3. **邮件兼容**:table 布局 + 全内联样式;`<style>` 仅含 `@font-face` 与 650px 媒体查询;无圆角、无阴影、无图片,任何客户端都不会破版。
4. **响应式**:≤650px 容器全宽、内边距收紧、焦点字号缩档、附录打分表隐藏"时效/重要/来源/完整"四列(桌面端完整)、市场数据带变两列堆叠。
5. **数据保真**:数字与文本逐字取自 `archives/2026-08-19.md`(60 个来源链接逐字核对);无涨跌数据以"—"占位。
6. **涨跌色**:V1/V3 按配方用批注墨标示变动(V1 钴蓝、V3 信号红),V2 薄荷绿;中国市场红涨绿跌语义由符号方向保留(本期全为下跌)。

## 使用方式

- **直接发送**:`powershell -File scripts/send_email.ps1 -SubjectFile <主题文件> -HtmlFile templates/v3-dark-terminal.html -DateStr 2026-08-19`
- **作为格式参照**:生成每日邮件的 AI 以任一版为版式基准,替换为当日数据。
- **重新生成/改版**:`node templates/build.mjs`;三版共用 `sample-data.mjs`,改数据只动数据文件,改配色/字号只动对应 render 内的常量。
